# Firefly OpenPlatform - Domain - Model Hub

Developed by the Firefly Software Foundation. [dev@fireflysoftware.io](mailto:dev@fireflysoftware.io)

[Website](https://fireflysoftware.io/) · [OpenPlatform](https://fireflysoftware.io/openplatform/) · [Module catalogue](https://fireflysoftware.io/openplatform/modules/)

Reads a virtual-entity record from core-common-modelhub through core-common-modelhub-sdk (`DynamicEntityApisApi.getRecordByIdForEntity`).

`firefly.modelhub.record.adapter` defaults to `sandbox`. `core` selects the SDK adapter. The sandbox returns one sample record and does not open a socket.
